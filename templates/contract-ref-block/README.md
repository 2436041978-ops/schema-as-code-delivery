# 契约引用块模板（Prompt 前缀的载体形态）

> 让契约进入 AGENTS.md / CLAUDE.md / Skill——不是第五种编译产物，是 Prompt 前缀打进文档级指令载体的形态。
> 配套角色：前端 / AI 工程师。

## 这是什么

编译产物仍是四种（Prompt 前缀 / JSON Schema / Checklist / CI 规则）。引用块是其中 Prompt 前缀的载体形态：同一份编译产物，打进文档级指令载体的文件格式里，附带契约编号与版本声明。

## 怎么用（一个动作，十分钟）

1. 从契约库取一份已评审通过契约的引用块（如 `ref-block-example-err001.md`，ERR-001 v1.2.0）；
2. 粘贴进仓库根目录的 AGENTS.md（或 CLAUDE.md / Skill 指令区）；
3. 用该仓库的 AI 编码工具发起一次相关生成，观察输出是否遵守引用块约束；
4. 反向验证：临时移除引用块，重跑同任务，对比两次输出——差异可复现，引用块在起作用。

## 两个格式要点

1. **注释头是机器契约，正文是人机共读。** 对账系统只认注释头里的 `contract_id + version`；AI 工具只读正文。两部分缺一不可。
2. **摘要的措辞严格程度必须与契约一致。** "禁止"在引用块里不允许写成"建议"——措辞弱化是最隐蔽的分叉。

## 两个纪律

- **引用块由编译管线生成，禁止手改内容。** 要改约束，改契约，走评审。
- **载体约束是概率执行，契约产物是确定执行。** 引用块管"生成时往正确的方向偏"，JSON Schema 与 CI 规则管"跑偏了必被拦"——前者不替代后者，挂了引用块仍要挂 Schema 和 CI。
