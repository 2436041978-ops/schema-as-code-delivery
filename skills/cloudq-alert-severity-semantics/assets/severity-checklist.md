# 告警文案语义走查清单

## 定级检查
- [ ] 告警级别按"用户承受的后果"判定，而非按指标阈值判定？
- [ ] 同一告警在不同场景下保持了级别一致性？

## 措辞检查
- [ ] fatal 级包含"不可恢复"或"立即处理"语义？
- [ ] 提供了恢复路径或下一步指引？
- [ ] transient 级避免了红色/紧急措辞？
- [ ] 标注了预计恢复时间？

## 术语防火墙检查
- [ ] 关键术语被同义词替换？（对照 references/severity-levels.md）
- [ ] 替换后用户的紧急程度判断发生变化？

## 处置边界检查
- [ ] 所有处置建议标注"需用户确认"？
- [ ] fatal 级处置有二次确认步骤？
- [ ] transient 级告警避免了破坏性处置建议？
